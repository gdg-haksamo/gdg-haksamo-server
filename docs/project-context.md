# 학사모 — 프로젝트 컨텍스트

## 개요
경북대학교(KNU) 학생을 위한 AI 기반 학식 추천 PWA.

## 기술 스택
| 구분 | 기술 |
|------|------|
| Backend | Spring Boot 3.5.x, Java 17 |
| DB | MySQL |
| 인증 | Spring Security + JWT (JJWT 0.12.6) |
| AI | Gemini 1.5 Flash (Vertex AI) |
| 알림 | FCM (Firebase Cloud Messaging) |
| 배포 | AWS EC2 |
| Frontend | React, TypeScript, Tailwind CSS, Vite |

## 핵심 도메인
- **식당**: 공식당(학생), 공식당(교직원), 복지관, 정보센터, 카페테리아 첨성 (5곳)
- **사용자 인증**: 이메일 형식·중복·소유(인증번호) 검증 기반 자체 회원가입 (3단계, 도메인 제한 없음)
- **메뉴 데이터**: 경북대 생협 사이트 크롤링 + 관리자 수동 수정/등록
  - 이미지·한줄설명·영양정보(탄단지·칼로리)는 크롤링이 아니라 **신규 메뉴 첫 크롤링 시 Gemini로 생성** (기존 메뉴는 스킵 → 비용 절감)

## MVP 핵심 기능
1. **메뉴 조회**: 식당별 날짜·끼니별 메뉴 (아침/중식/저녁 토글, 현재 시각 기준 default)
2. **메뉴 상세**: 메뉴 정보 + 영양정보(탄단지·칼로리) + 별점 분포 그래프(1~5점) + 리뷰 리스트
3. **리뷰**:
   - 별점(1-5) + 한줄평
   - 메뉴별 리뷰 개수 노출 (좋아요/하트는 미도입)
   - **리뷰 "도움됐어요"** (다른 사람의 리뷰에 표시)
4. **AI 학식 추천 (Gemini)**:
   - 자동: 하루 1회 캐싱 (첫 요청 시 생성, 이후 DB 반환)
   - 새로고침: 동일 row UPDATE로 재생성 (히스토리 미보존), 하루 최대 **3회** 제한
   - 중복 방지: 이미 추천한 메뉴는 재추천하지 않음 (`excluded_menu_ids` 누적)
   - 응답: 추천 메뉴 + 한줄설명(AI) + 탄단지/칼로리
5. **푸시 알림 (FCM)**:
   - 끼니별 토글: 아침 / 점심 / 저녁 (각각 on/off)
   - 발송 시각(Figma 기준): 아침 **07:30** / 점심 **11:30** / 저녁 **17:30** "추천 메뉴 알림"
   - 이벤트/공지 알림 on/off
   - 마스터 푸시 on/off (전체 차단)
   - 알림 본문 예: "오늘의 점심 학식 추천: {메뉴명}"
6. **검색**: 식당명·메뉴명 검색
7. **공지사항·이벤트 페이지**: 운영자 등록 콘텐츠 노출 (인스타 등 외부 SNS 연동 X)
8. **마이페이지**:
   - 선호 키워드 (가입 시 수집 + 마이페이지에서 수정) — 고정 칩 선택, 선호(LIKED) 위주
   - **자주 가는 학식당** (N개 등록 가능)
   - 프로필: 닉네임 / 학과 / 학년
   - 본인 리뷰가 받은 "도움됐어요" 누계
   - 알림 설정
9. **회원가입/로그인**: 이메일 + 비밀번호 (도메인 제한 없음, 이메일 인증으로 소유 검증), JWT 발급
   - 회원가입 3단계: ①이메일 인증(인증번호 6자리·3분) ②기본정보(닉네임·비번·학과) + 자주 가는 식당 ③선호 키워드 선택
   - 로그인 유지: Access(메모리) + Refresh(httpOnly 쿠키, 회전)
   - 비로그인 접근: 오늘 메뉴 리스트만 공개, 추천·상세·기타는 401 → 로그인 유도
10. **관리자 RBAC (RESTAURANT_ADMIN=식당 운영자, 자기 식당만 / SUPER_ADMIN=운영팀, 전체+계정관리)**: 클릭 한 번으로 품절 처리(`MenuSchedule.is_sold_out`), 신메뉴 등록, 메뉴 이름·가격 수정 (식당 단위 권한은 `RestaurantAdminGuard`, erd-decisions #27)
    - 로드맵: **2026-07-05 공식당 관리자 페이지 선제공**, **2026-07-10 베타 런칭** (출처: docs/meeting-gongsikdang.md)

## 후순위 기능
- 교내 식당 위치 지도 (실제 지도 X, 5구역 그림 지도 → 식당 위치 매핑)
- 알림 내역 조회 (Notification 테이블은 MVP에서 미리 준비)
- 리뷰 이벤트 + "도움됐어요" 순 당첨자 뽑기 (4주 범위 초과)
- 외부 SNS(인스타 등) 이벤트 연동
