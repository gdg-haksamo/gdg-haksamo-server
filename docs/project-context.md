# 학사모 — 프로젝트 컨텍스트

## 개요
경북대학교(KNU) 학생을 위한 AI 기반 학식 추천 PWA.

## 팀
| 이름 | 역할 |
|------|------|
| 배성민 | FE |
| 최원아 | FE |
| 김동우 | BE |
| 김채윤 | BE |

## 기술 스택
| 구분 | 기술 |
|------|------|
| Backend | Spring Boot 3.5.x, Java 17 |
| DB | MySQL |
| 인증 | Spring Security + JWT (JJWT 0.12.6) |
| AI | Gemini 1.5 Flash (Vertex AI) |
| 알림 | FCM (Firebase Cloud Messaging) |
| 배포 | AWS EC2 |
| Frontend | React, TypeScript, Tailwind CSS, Vite |

## 핵심 도메인
- **식당**: 첨성관, 공과대 식당, 정보전산원 (3곳)
- **사용자 인증**: @knu.ac.kr 이메일 도메인 검증, 자체 회원가입
- **메뉴 데이터**: 경북대 생협 사이트 크롤링 + 관리자 수동 수정 fallback

## MVP 핵심 기능
1. **메뉴 조회**: 식당별 날짜·끼니별 메뉴 (아침/중식/저녁 토글, 현재 시각 기준 default)
2. **메뉴 상세**: 메뉴 정보 + 영양정보(탄단지·칼로리) + 별점 분포 그래프(1~5점) + 리뷰 리스트
3. **리뷰**:
   - 별점(1-5) + 한줄평
   - 메뉴별 리뷰 개수 노출 (좋아요/하트는 미도입)
   - **리뷰 "도움됐어요"** (다른 사람의 리뷰에 표시)
4. **AI 학식 추천 (Gemini)**:
   - 자동: 하루 1회 캐싱
   - 새로고침: 동일 row UPDATE로 재생성 (히스토리 미보존)
   - 응답: 추천 메뉴 + 한줄설명(AI) + 탄단지/칼로리
5. **푸시 알림 (FCM)**:
   - 끼니별 토글: 아침 / 점심 / 저녁 (각각 on/off)
   - 이벤트/공지 알림 on/off
   - 마스터 푸시 on/off (전체 차단)
   - 알림 본문 예: "오늘의 점심 학식 추천: {메뉴명}"
6. **검색**: 식당명·메뉴명 검색
7. **공지사항·이벤트 페이지**: 운영자 등록 콘텐츠 노출 (인스타 등 외부 SNS 연동 X)
8. **마이페이지**:
   - 선호/기피 키워드 (가입 후 설정, 가입 시는 받지 않음)
   - **자주 가는 학식당** (N개 등록 가능)
   - 본인 리뷰가 받은 "도움됐어요" 누계
   - 알림 설정
9. **회원가입/로그인**: 이메일(@knu.ac.kr) + 비밀번호, JWT 발급
10. **관리자**: 메뉴 수정, 품절 처리

## 후순위 기능
- 교내 식당 위치 지도 (실제 지도 X, 5구역 그림 지도 → 식당 위치 매핑)
- 알림 내역 조회 (Notification 테이블은 MVP에서 미리 준비)
- 리뷰 이벤트 + "도움됐어요" 순 당첨자 뽑기 (4주 범위 초과)
- 외부 SNS(인스타 등) 이벤트 연동

## 개발 일정 (4주)
| 주차 | BE 목표 |
|------|--------|
| 1주차 | ERD 확정, 엔티티 생성, 크롤러, 식당·메뉴 조회 API |
| 2주차 | Auth API, 리뷰 API, 선호 설정 API |
| 3주차 | Gemini AI 추천, FCM 푸시 알림, 관리자 API |
| 4주차 | EC2 배포, QA, FE 연동 |
