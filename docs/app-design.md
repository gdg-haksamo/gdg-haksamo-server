# 학사모 앱 화면·기능 설계 (FE/BE 공통 참고)

기획 이미지 [`학사모.png`](./학사모.png) 와 [`학사모 앱 설계.webp`](./학사모%20앱%20설계.webp) 를 텍스트로 정리한 문서.
디자인 변경이 일어나면 이 문서와 이미지를 동시에 갱신한다.

> **이미지 표기 규칙**
> - **화살표(→)**: 화면 이동을 의미
> - **X 표시**: 해당 기능/요소는 도입하지 않음 (미구현)

---

## 0. 화면 인벤토리

| 화면 | 진입 경로 | 비고 |
|---|---|---|
| 홈 | 앱 시작 (로그인 후) | 오늘의 추천 + 식당별 메뉴 리스트 |
| 메뉴 상세 | 홈/검색에서 메뉴 클릭 | 영양 정보, 별점 그래프, 리뷰 |
| 검색 | 푸터 검색 탭 | 식당·메뉴 통합 검색 |
| 지도 | 푸터 지도 탭 (후순위) | 그림 지도(5구역), 식당 핀 |
| 공지·이벤트 | 헤더 🔔 아이콘 | 운영자 등록 콘텐츠 |
| 마이페이지 | 푸터 마이페이지 탭 | 키워드/자주 가는 식당/알림 설정 |
| 키워드 수정 모달 | 마이페이지 → 키워드 카드 | |
| 회원가입 | 미로그인 진입 | 이메일 + 기본 정보 (키워드는 받지 않음) |
| 로그인 | 미로그인 진입 | |

## 1. 홈 화면

### 헤더
- 좌: 학교명 ("경북대학교 학식")
- 우: 🔔 아이콘 → **공지·이벤트 페이지** 이동

### 오늘의 추천 메뉴 (메인 카드)
- AI(Gemini)가 사용자 선호 기반으로 추천한 메뉴 1건 카드
- 구성:
  1. 메뉴 한줄설명 (AI 생성)
  2. 탄단지·칼로리
  3. 식당 이름 및 정보 (짧게)
  4. 리뷰 3개 미리보기 + **리뷰 전체보기** 버튼 → 메뉴 리뷰 상세 페이지
- **새로고침 버튼**: 추천 메뉴 다시 생성 (`Recommendation` row UPDATE)
- 카드 클릭 → 메뉴 상세 페이지

### 끼니 토글 (아침 / 중식 / 저녁)
- 현재 시각 기준 default 선택
- BE: `Menu.time ENUM('BREAKFAST','LUNCH','DINNER')` 매핑

### 식당 메뉴 리스트
- 사용자가 **자주 가는 학식당**을 우선 default로 노출
- 각 메뉴: 이름 / 가격 / ★ 리뷰 개수
- 클릭 → 메뉴 상세 페이지
- **하트/좋아요는 도입하지 않음** — 리뷰 개수가 인기 지표

### 푸터 (탭바)
- 홈 / 검색 / 지도 / 마이페이지

---

## 2. 메뉴 상세 페이지

- 메뉴 사진, 이름, 가격, 식당 정보
- 영양 정보 (탄·단·지·칼로리 차트)
- **별점 그래프**: 5/4/3/2/1점 분포 막대그래프 + 평균 별점 (예: 4.4)
- 리뷰 리스트
  - 각 리뷰에 **"도움됐어요" 버튼** (1 사용자 = 1 리뷰에 1회)
  - 리뷰별 도움됐어요 카운트 노출
- 리뷰 작성 폼 (별점 1~5 + 텍스트)

---

## 3. 검색

- 검색 대상: **식당명**, **메뉴명**
- 필터: 식당 → 메뉴 순으로 좁히기, 최신순 정렬
- 사용 예: "수육" 검색 → 해당 메뉴 제공 식당 위치가 지도에서 강조 (지도 기능 도입 시)

---

## 4. 지도 (후순위)

- **실제 지도 API는 사용하지 않음** — 학교 그림 지도 (5구역 색상 구분)
- 식당 위치 = 그림 좌표 (`Restaurant.map_x`, `map_y`)
- 핀 클릭 → 해당 식당 홈(메뉴 리스트) 화면으로 리디렉트

---

## 5. 공지·이벤트 페이지

- 헤더 🔔 아이콘으로 진입
- 운영자가 `Event` 테이블에 등록한 공지/이벤트 카드 리스트
- **인스타 등 외부 SNS 연동은 미도입** (X 표시)

---

## 6. 마이페이지

### 6-1. 프로필 카드
- 닉네임 / 학교 / 학번
- **본인 리뷰가 받은 "도움됐어요" 누계** (가운데 큰 숫자로 표시)
- 좌우 추가 통계 위젯은 도입하지 않음 (X 표시)

### 6-2. 자주 가는 학식당
- 사용자가 등록한 식당 리스트 (N개)
- 홈 화면 default 노출 식당 결정에 사용
- BE: `FavoriteRestaurant (user_id, restaurant_id)` 복합 PK 테이블

### 6-3. 선호 음식 설정 (키워드 카드 → 키워드 수정 모달)
- 음식 키워드 자유 입력/선택
  - 카테고리 예: 매운 / 단 / 짠 / 신 / 순한
  - 종류 예: 한식 / 양식 / 중식 / 일식
- 선호(LIKED) / 기피(DISLIKED) 구분
- BE: `Preference (user_id, keyword, type ENUM('LIKED','DISLIKED'))`

### 6-4. 알림 설정
| 토글 | 컬럼 |
|---|---|
| 푸시 알림 (마스터) | `push_notification_enabled` |
| 아침 알림 | `notification_breakfast_enabled` |
| 점심 알림 | `notification_lunch_enabled` |
| 저녁 알림 | `notification_dinner_enabled` |
| 이벤트/공지 알림 | `notification_event_enabled` |

마스터 토글이 OFF면 개별 토글 상태와 무관하게 발송 중단.

## 7. 푸시 알림

- 발송 시점: 매일 아침 / 점심 / 저녁 (스케줄러)
- 발송 대상 조건:
  1. `push_notification_enabled = TRUE`
  2. 해당 끼니 토글이 `TRUE`
  3. `fcm_token IS NOT NULL`
- 알림 본문: `오늘의 {끼니} 학식 추천: {메뉴명}`
- 푸시 클릭 → 해당 추천 메뉴 상세 페이지로 딥링크
- 발송 기록은 `Notification` 테이블에 저장 (조회 UI는 후순위)

---

## 8. 회원가입 / 로그인

### 회원가입 흐름
1. **메인** — 로그인 / 회원가입 선택
2. **이메일 회원가입** — 이메일(@knu.ac.kr), 비밀번호, 닉네임 등 기본 정보 입력
3. **완료** → 자동 로그인 → 홈

> 회원가입 시 키워드 선택 단계는 **도입하지 않음 (X 표시)**.
> 가입 후 마이페이지에서 키워드를 설정할 수 있음. 키워드 미설정 사용자도 일반 추천이 동작.

### 로그인
- 이메일 + 비밀번호
- 응답: Access Token + Refresh Token (JWT)

## 9. 도입하지 않는 기능 (기획서 X 표시)

| 기능 | 사유 |
|---|---|
| 리뷰 이벤트 + 당첨자 뽑기 (도움됐어요 순) | 4주 MVP 범위 초과 |
| 인스타 등 외부 SNS 이벤트 연동 | 4주 MVP 범위 초과 |
| 회원가입 시 키워드 선택 | 진입 장벽 완화 — 가입 후 설정 |
| 마이페이지 프로필 카드 좌우 위젯 | 디자인 단순화 |
| 좋아요/하트 | 리뷰 개수로 대체 |
| 알림 내역 조회 화면 | 후순위 (테이블만 준비) |
| 실제 지도 API 연동 | 그림 지도로 대체 |
